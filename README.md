C++ Technology Quiz 📱💻
A console-based technology quiz application written in C++ - coded entirely on an Android phone over 3 weeks during leisure time!

🎯 About This Project
This was one of my first programming projects, created when I was just starting to learn C++. What makes it special? I wrote the entire thing on my Android phone using the Android CPP app, dedicating my free time over 3 weeks to bring this idea to life.

✨ Features
User Authentication System
Account creation with password verification
Login functionality
Input validation


Three-Level Quiz System
Light Level: Basic IT terminology (10 questions)
Moderate Level: Multiple choice technical concepts (10 questions)
Heavy Level: Computer science history and advanced topics (10 questions)


Scoring & Analytics
Real-time score tracking
Level-by-level performance analysis
Final grade calculation with percentage
Pass/fail determination (70% threshold)


User Experience
Interactive prompts and confirmations
Clear instructions and feedback
Progress indicators
Motivational messages



🚀 How to Run
Option 1: Online IDEs (Easiest for Beginners)  🌐
Quick Start - No Installation Required:
-Programiz Online Compiler: https://www.programiz.com/cpp-programming/online-compiler/
Copy and paste the code
Click "Run" to execute
Perfect for beginners!
-GDB Online Compiler: https://www.onlinegdb.com/online_c++_compiler
Copy and paste the code
Select C++ language
Click "Run" to start the quiz

Option 2: Local Installation (Advanced)
Prerequisites: Make sure you have a C++ compiler installed (g++, clang++, or Visual Studio)
Compile the program:
bashg++ -o quiz quiz.cpp

Run the executable:
bash./quiz        # On Linux/Mac
quiz.exe      # On Windows


📱 Mobile Users
Since this was originally coded on mobile, you can also run it using:
Android: C4droid, AIDE, or QPython apps
iOS: Buffer Editor or other C++ mobile IDEs

🎮 How to Play
Create an account or exit
Log in with your credentials
Follow the instructions carefully
Answer questions using CAPITAL LETTERS
Progress through three difficulty levels
View your final score and performance analysis

🐛 Known Issues (Beginner Code Alert!)
As this was written when I was just starting out, there are some areas that could be improved:
Frequent use of exit(0) instead of proper flow control
Some infinite loops that break immediately
Variable scope could be better organized
Hard-coded values that could be made configurable

These quirks are preserved to show the authentic learning journey!
📱 The Mobile Coding Story
This entire project was written on an Android phone using the Android CPP app. Coding on mobile presented unique challenges:
Limited screen space for viewing code structure
Difficult text editing and navigation
No syntax highlighting or auto-completion
Challenging debugging process

Despite these constraints, the project was completed as a hobby during leisure time, demonstrating that passion for programming can overcome any limitation!
